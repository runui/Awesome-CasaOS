# Upstream platform declarations

Reviewed on 2026-10-16. These declarations follow upstream documentation; they are not claims that every application was installed and tested on a device. Only platforms with a verified native installation source are recorded. ZimaOS requires a JSON manifest: app compatibility statements do not turn CasaOS ZIP archives into ZimaOS sources. A CasaOS-only entry means ZimaOS support has not been confirmed for this listing.

The [ZimaOS community stores documentation](https://www.zimaspace.com/docs/zimaos/app-store/awesome-third-party-stores), last updated 2026-10-13, supplies the native source URLs for Play, Big Bear, and Lintuxer. Each listed `store.json` and its accompanying `index.json` were fetched and parsed as version 2 JSON. The published indexes contained 154, 243, and 13 apps respectively at the time of this review, and a sample app's `meta.json` was fetched successfully from each index. Big Bear's CDN manifest was also checked against the repository's `gh-pages` branch. Published branches and hosted sources must be checked alongside default-branch READMEs.

To update a declaration, verify the relevant upstream README, release, or installation documentation and update this record with the supporting link. Different platforms may use entirely different source formats. Never derive a ZimaOS URL by replacing a path segment or file extension in a CasaOS URL.
